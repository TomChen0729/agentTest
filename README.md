## 使用方法
1. 啟動資料抓取：`python scraper/scraper.py`
2. 資料處理：`python data/data.py`
3. 產生視覺化結果：`python visualizer/visualizer.py`

## 檔案結構
- `config/`：配置檔案
- `data/`：資料處理模組
- `scraper/`：資料抓取工具
- `visualizer/`：視覺化腳本
- `requirements.txt`：依賴清單
